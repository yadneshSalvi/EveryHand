# Local visual dependencies

DM Sans and DM Serif Display are the app’s shipped font families. SIL Open Font Licenses are preserved beside this file. The DM Serif Display license source is https://raw.githubusercontent.com/google/fonts/main/ofl/dmserifdisplay/OFL.txt. GSAP 3.14.2 is pinned in package-lock.json; its runtime banner and README are preserved. Its package metadata names the Standard no-charge license at https://gsap.com/standard-license. App favicon and captured product pixels come from this repository.
